# Pendalaman yang masih terbuka

Seluruh 40 domain memiliki authored core. Target pengguna tetap pengetahuan sangat mendalam; release ini tidak mengubah target menjadi outline-only. Isi inti tersedia, sementara full specialist depth berikut belum dinyatakan selesai:

- Derivations/implementations lengkap untuk seluruh FEM/FVM, turbulence, fracture dan coupled multiphysics.
- Independent experiment reproduction untuk learned motion, reinforcement learning dan dataset generalization.
- Validated capture/sensor calibration pada perangkat nyata.
- Production rigs, human performance dan biomechanical validation pada actual assets/observations.
- GPU/browser/XR/haptic/robot execution dan performance matrix pada target nyata.
- Human perception/comfort/usability studies dan accessibility audits yang sesuai produk.
- Passage-level audit seluruh technical syntheses dan setiap source candidate.
- Media render/decode dan delivery examples pada actual export target.

Bukan kosong: handbook terkait menjelaskan concepts, procedures, failure modes dan verification paths. Open gap menyatakan batas depth/evidence, bukan menghilangkan scope. Per topic status ada di `coverage.json`; update hanya berdasarkan pekerjaan nyata.
