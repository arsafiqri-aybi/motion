# Kebijakan bukti dan kedalaman

Repo ini menyediakan core knowledge 40 domain dan 280 subdomain. `AUTHORED_CORE` berarti explanation, model/procedure, failures dan verification ditulis. Itu bukan sertifikasi encyclopedic completeness atau seluruh scientific claims terverifikasi.

Pisahkan lima kelas: mathematical derivation (assumptions ditulis), technical synthesis (pengetahuan engineering), standard/API statement (versi/passage), empirical scientific finding (population/system/method), dan authored heuristic/policy (pilihan desain). Dilarang mempromosikan heuristic menjadi universal fact atau synthetic fixture menjadi human/device result.

Sumber candidate tidak mendukung claim sebelum passage yang relevan dibaca. Index inspection hanya membuktikan scope yang terdaftar. Draft W3C tetap dilabeli draft; published document tidak menjamin implementation semua browsers.

Depth stages: scoped → authored core → detailed derivation → implemented → independently tested → passage audited → specialist monograph. Different branches dapat berada pada stages berbeda. Jangan menghitung stage terdalam domain hanya karena satu lab di dalamnya lulus.

Numerical PASS hanya meliputi assumptions/fixtures tested. Link validation tidak memverifikasi source science. Repo tidak mengklaim trained neural graph, user study, accessibility certification, hardware validation, atau all-platform benchmark.

Untuk pendalaman: pilih topic ID; retrieve primary sources; catat claims dan passage/version; tulis derivation dan alternatives; implementasikan bila appropriate; uji independent oracle; hubungkan graph; update coverage dengan evidence actual. Pertahankan sejarah dan open gaps.
