## Cara menggunakan konsep

Baca full subsection termasuk failure/verifier sebelum menyalin equation. Tulis unit/frame/time, initial conditions dan intended outcome. Pilih implementation path sesuai capability actual. Jalankan appropriate independent fixture. Ketika istilah unclear, gunakan [glossary](glossary.md); ketika symptom unclear gunakan [diagnostics](../diagnostics/README.md).

`python3 scripts/search.py "spring"` adalah literal local retrieval, bukan semantic AI atau trained neural network. Search snippets membantu navigation, bukan menggantikan source passage atau full explanation.
